device.mytesla

This hostname belongs to myTesla, an open-source Raspberry Pi appliance that streams Apple CarPlay into a Tesla's built-in browser.

Why you're seeing this

Inside a car, this name resolves to the myTesla device on its own Wi-Fi network — never to this page. You're seeing this because you opened it from an ordinary internet connection, where the name points here instead.

Is this tracking me?

No. This is a static page. The hostname exists so each device can serve HTTPS with a browser-trusted certificate; no vehicle, location, or personal data passes through it.

Running a device?

Join the Pi's Wi-Fi access point from the car, then open https://device.mytesla.humblebees.co in the Tesla browser. Setup instructions ship with the project.
