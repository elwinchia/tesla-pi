2 · Is there an adapter at all?

A blocklisted driver does not hide navigator.gpu — it hands back a null adapter. Both power preferences are tried, because a car may expose only one.

3 · Limits that decide whether a model fits

WebLLM uploads model weights as storage buffers. maxStorageBufferBindingSize is the one that bites: at the 128 MB spec floor, weights must be split into many more shards, and some MLC builds simply refuse.

4 · Does a compute shader actually run?

Objects existing proves nothing. This dispatches a kernel and checks the values that come back.

5 · 16-bit float

Not a nicety. Without shader-f16 the model runs in f32 and both bandwidth and memory roughly double, which is the difference between a usable companion and a slideshow.

not run

6 · How fast, really

Token decode is bandwidth bound — every generated token reads the whole model once. So this streams a large storage buffer through the GPU and reports GB/s, then divides by a model size to get the ceiling. Treat the tokens/sec figures as an upper bound; a real engine lands somewhere near half.

7 · Does it work inside a Worker?

static/worker.js is where this project renders from. A WebGPU that only works on the main thread is not usable for the RetroArch upscaler without restructuring — though an LLM, which needs no canvas, would still be fine.

not run

8 · Will it let us cache a model?

WebLLM keeps ~1–1.5 GB of weights in the Cache API and reads from there on every later boot. If the car's browser caps us well under that, the LLM plan dies here regardless of the GPU. The write test moves 64 MB and cleans up after itself.

not run

9 · BLE — can the browser reach the car?

Vehicle state (charge, climate, doors, lock) is what turns a chatbot into a driving companion. Tesla exposes it over BLE with no internet and no Fleet API — the open question is whether the browser can speak it, which would move that whole leg off the Pi. Expect no. Web Bluetooth is only partially implemented on Chromium for Linux and needs an experimental flag we cannot set on a car. A cheap no is still worth having, and a yes is a real simplification.
