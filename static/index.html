Path CERT_PATH

Renewing the certificate restarts the configuration access point for approximately 5 minutes. Your CarPlay session won't be interrupted — only the on-board admin Wi-Fi briefly drops while the new cert is installed. Only useful when the Pi is parked within range of the home Wi-Fi configured in wpa_supplicant-wlan0-home.conf.

Android (Waydroid)

experimental
Experimental. Adds an Android tile to the launcher that streams Waydroid (Waze & maps) to the Tesla browser over H.264. Off by default; saved per-browser.

Display

screen layout
Full screen fills the Tesla browser with CarPlay. 16:8 shrinks CarPlay to a top band and frees a control dock below it. Changing this restarts the CarPlay session and reloads the page. Saved on the Pi.

Frame rate

CarPlay stream
Changing this restarts the CarPlay session — the screen will briefly show the reconnecting overlay. 30 fps cuts dongle load and bandwidth roughly in half; 60 fps is smoother. Saved on the Pi.

Hand

driver position
Tells the dongle which side you're sitting on so CarPlay puts lane guidance and key UI on the correct side. Changing this restarts the CarPlay session. Saved on the Pi.

Show FPS

on the CarPlay screen
Counts video frames arriving from the dongle, refreshed once a second. Drawn as a small pill in the corner. Saved per-browser.
